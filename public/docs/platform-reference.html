Complete reference for all Platform Console sections, fields, validation rules, and examples.

🛡️ Provisioning

Purpose: Global security policies and new-store defaults

Credential Policy

FieldTypeRequiredDefaultDescription
Minimum password length Number Optional 8 Min characters for user passwords
Require letter + digit Boolean Optional false Enforce mixed character types
Block breached passwords Boolean Optional false Reject known compromised passwords

New-Store Defaults

FieldTypeRequiredDefaultDescription
Default plan String Optional "starter" Tier assigned to new stores (starter/professional)
Seed demo catalog Boolean Optional false Auto-add sample products on launch
Gateways sandbox mode Boolean Optional true Start payment providers in test mode

🏬 Stores (Tenant Management)

Purpose: Launch and manage store tenants

Launch Wizard Fields

FieldTypeRequiredDefaultDescription
Name String Required — Display name (e.g., "Luxora Fashion")
Slug String Required — URL identifier (e.g., "luxora") - unique
Tagline String Optional — Short description shown on storefront
Jurisdiction Country String Required — Country code (US, IN, AE) - auto-loads currency/tax
Industry / Departments Array Optional [] Selected industries (fashion, grocery, etc.)
Owner Email String Optional — Admin email for store owner
Gateway Providers Array Optional [] Payment providers for this country
Example Launch:
{ name: "Luxora", slug: "luxora", jurisdiction: "US", industries: ["fashion"], ownerEmail: "owner@luxora.com" }

🌍 Geo · Countries · Taxes

Purpose: Define countries, currencies, tax modes, provider availability

Country Configuration

FieldTypeRequiredDefaultDescription
Country Code String Required — ISO 3166 code (US, IN, AE, DE)
Base Currency String Required — Currency code (USD, INR, AED)
Tax Mode String Optional none Tax type: sales_tax, vat, gst, none
Tax Rate Number Optional 0 Default tax rate (e.g., 0.19 for 19%)
Provider Availability Array Optional [] Enabled payment/shipping providers

💼 Plans (Subscription Tiers)

Purpose: Define store subscription tiers

Plan Fields

FieldTypeRequiredDefaultDescription
Name String Required — Plan name (Starter, Professional, Enterprise)
Price (Monthly) Number Required 0 Monthly subscription price
Max Products Number Optional 100 Max products store can list
Max Orders / Month Number Optional 100 Max orders processed per month

🔌 Provider Registry

Purpose: Register and configure payment, shipping, notification providers

Provider Fields

FieldTypeRequiredDefaultDescription
Provider ID String Required — Unique identifier (stripe, razorpay, tabby, aramex)
Type String Required — payment, shipping, notification, tax
Available Countries Array Required [] Country codes where provider works
API Credentials Object Optional {} API keys (sealed at rest)
Sandbox Mode Boolean Optional true Test mode (true) or live mode (false)
Example:
{ id: "stripe", type: "payment", countries: ["US", "AE"], sandbox: true }
