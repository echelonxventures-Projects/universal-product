⚙️ Platform Provisioning Guide

Location: Platform Console → 🛡️ Provisioning

This page documents all platform security policies and store defaults. Each field affects either user security, platform protection, or default behavior for new stores.

1. Credential Policy

Controls password requirements and hashing for all user accounts (platform, store admins, customers).

Important: Changes apply to new/rotated credentials only. Existing accounts upgrade transparently on next login.

Protects platform from brute-force attacks and DoS/DDoS attempts.

Warning: Values too low = legitimate users locked out. Values too high = platform vulnerable to attacks.

Quick Reference: Security Levels

Development / Demo

  • Password length: 8
  • Block breached passwords: On
  • Demo hints: On
  • Sandbox gateways: On
  • Seed demo catalog: On

Production (Standard)

  • Password length: 12
  • Require letter + digit: On
  • Block breached passwords: On
  • Demo hints: Off
  • CSP inline style: Off
  • Sandbox gateways: On → Enable live manually

Production (Enterprise / Strict)

  • Password length: 16
  • Require letter + digit: On
  • Block breached passwords: On
  • CSRF: On
  • Lockout: 5 attempts → 30s → max 15min
  • Fiscal context pickers: On (for B2B)
