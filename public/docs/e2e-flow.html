✅ End-to-End Workflow

Complete workflow for launching a new store, configuring it, and processing the first order.

1
Platform Global Setup
Location: Platform Console → 🛡️ Provisioning

Configure Security Policy

  • Set Minimum password length to 12
  • Enable Require letter + digit
  • Enable Block common/breached passwords

Configure Countries & Taxes

Location: 🌍 Geo · Countries · Taxes
  • Verify AE (UAE) exists with AED currency and VAT tax
  • Verify US exists with USD currency and Sales Tax

Create Plan

Location: 💼 Plans
  • Click New Plan
  • Name: Professional
  • Max Products: 1000
  • Max Orders/Month: 1000
  • Click Create
2
Launch First Store
Location: Platform Console → 🏬 Stores

Launch Wizard

  • Name: Velora Fashion
  • Slug: velora
  • Jurisdiction: United Arab Emirates (AE) (Auto-loads AED, VAT)
  • Industries: Fashion
  • Gateways: Tabby, Stripe
  • Plan: Professional
  • Click Launch
Expected Result:
Store created. Admin email: admin@velora.shop
Password provided on screen (e.g., velora123)
3
Store Configuration
Location: Store Console → http://localhost:8787/admin.html?store=velora

Settings & Branding

Location: ⚙️ Settings
  • Store Name: Velora
  • Tagline: Premium Fashion UAE
  • Currency: AED (Auto-set)

Add Products

Location: 📦 Products
  • Click New Product
  • Title: Silk Dress
  • Brand: Velora
  • Price: 250
  • Stock: 50
  • Lifecycle: Published
  • Click Save

Enable Payment

Location: 💳 Payment Gateways
  • Ensure Tabby is set to Primary
  • Click Activate (switch to Live mode if ready)
4
Create Offer
Location: Store Console → 🎯 Promotions

New Promotion

  • Type: Percent
  • Code: WELCOME20
  • Value: 20 (20%)
  • Min Cart: 100
  • Start: Today
  • End: End of Month
  • Click Save
Test:
Go to Store Console → Ω∞ GOIP → Decision Tester
Enter: Amount 250, Code WELCOME20
Result: APPROVED (Discount: 50 AED)
5
Customer Purchase (Frontend)
Location: Storefront → http://localhost:8787/?store=velora

Browse & Add to Cart

  • Go to http://localhost:8787/?store=velora
  • Search for Silk Dress
  • Click Add to Cart
  • Click Cart icon (top right)

Apply Code & Checkout

  • Enter Promo Code: WELCOME20
  • Click Apply (Total becomes 200 AED)
  • Click Checkout
  • Enter Shipping Details (Name, Address, Phone)
  • Select Payment: Tabby or Credit Card
  • Click Place Order
Success! Order created. You will see Order # (e.g., ORD-2025-0001).
6
Order Fulfillment
Location: Store Console → 🧾 Orders

Process Order

  • Open the new order
  • Check Payment Status: Captured
  • Check Inventory: Stock reduced by 1
  • Update Status to Shipped when ready
  • Enter Tracking Number
Done! Order complete. Customer receives shipping update.
